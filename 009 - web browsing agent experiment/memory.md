1. Created WebAgent class to interact with websites using Puppeteer. The agent provides methods for browser initialization, navigation, element interaction (clicking, typing), keyboard input, waiting for elements/navigation, taking screenshots, and extracting text content. All actions automatically capture screenshots to document the process, with screenshots saved in a timestamped format in the ./screenshots directory. The agent handles errors gracefully and provides appropriate logging for each action. The implementation ensures a clean separation of concerns between web interaction functionality and the LLM instructions that will use these capabilities.

2. Created a comprehensive prompt in index.ts that describes how to use the WebAgent API. The prompt includes detailed descriptions of all available functions, their parameters, return types, and example usage. It also includes important notes about automatically taking screenshots, error handling, and proper initialization/cleanup. Additionally, provided guidance on common CSS selectors for web navigation tasks, particularly for Google search, to help the LLM generate effective code. Updated the main function to initialize the WebAgent and set up communication with the LLM, including passing the appropriate prompt and preparing for future code execution capabilities.

3. Implemented a closed-loop system where a vision-capable LLM (qwen2-vl-2b-instruct) uses the WebAgent to navigate websites. The system follows a cyclical process: the LLM examines a screenshot, decides on an action, the WebAgent executes the action, takes a new screenshot, and the LLM analyzes it to determine the next step. This creates a feedback loop that allows the agent to adapt to changing website states. The implementation includes action parsing logic to convert the LLM's text responses into WebAgent function calls, error handling, and safety features like a maximum step limit to prevent infinite loops. The task "Navigate to google.com, type 'AI' in the search box, search for results, and navigate to the first result" was integrated as the initial goal for the agent to accomplish.
