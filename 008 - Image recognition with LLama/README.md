# LLama Image Recognition

A TypeScript application that uses LM Studio with the Llama 4 Scout model for text generation.

## Requirements

- [LM Studio](https://lmstudio.ai/) installed and running
- Llama 4 Scout (17B) model loaded in LM Studio
  - You can get the model from LM Studio's model library

## Setup

1. Clone this repository
2. Install dependencies:
```bash
npm install
```

## Usage

1. Make sure LM Studio is running with the Llama 4 Scout model loaded
2. Run the project:
```bash
npm start
```

For development with auto-reload:
```bash
npm run dev
```

## Build

To compile TypeScript to JavaScript:
```bash
npm run build
```

The compiled output will be in the `dist` directory.
